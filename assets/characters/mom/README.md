# Мама в квартире

Модель из уже существующей игры: 31 602 вершины, 33 999 треугольников, 15 суставов, рост около 1,66 м. Упакованные сетка и текстуры сохранены в `mom-asset.json` без изменения. Индивидуальный масштаб X=+1 обязателен; группа компенсирует горизонтальный масштаб квартиры.

## Глаза

`eye-profile.json` содержит расположение глаз на исходном лице, глубины поверхности и цвета кожи век. `scripts/fit-mom-eyes.cjs` пересчитывает профиль по сетке и текстуре. `mom-eyes.js` добавляет две облегающие поверхности с радужкой, зрачком и переходом к коже по краям. Глаза следуют голове; моргание и сон закрывают их цветом век. Цветовая карта тела использует sRGB.

## Движение и пульт

`mom-runtime.js` сохраняет ежедневный распорядок: сон, ванная, готовка, еда, отдых и телевизор. Ходьба использует существующее движение студентов с адаптацией к пропорциям мамы.

В 19:15 она встаёт, подходит к существующему столику, наклоняется, берёт пульт правой рукой, подходит к дивану, направляет пульт на ТВ, нажимает кнопку и плавно садится. Пульт закрепляется на кисти с постоянным смещением; IK рассчитывается из его положения и ориентации. В 22:30 она выключает ТВ, встаёт, возвращает пульт и ложится спать. Событие включения/выключения совпадает с нажатием кнопки.

Посадка рассчитана по существующей подушке дивана: таз находится над ней, колени перед её краем, стопы сохраняют ориентацию. У короткой модели ноги на высоком диване слегка свисают. Дополнительный столик не создаётся.

В состоянии покоя есть дыхание, небольшие движения корпуса, взгляд на ТВ и короткие взгляды на близко подошедшего игрока. Мама по-прежнему ждёт освобождения ванной и закрывает за собой дверь.

## Телевизор

`mom-tv.js` показывает целиком пользовательскую картинку `assets/television/mom-screen.jpg`; её пропорции сохраняются. Оригинальная гитарная мелодия хранится в `mom-guitar.wav`. Расстояние до экрана и комната игрока влияют на громкость с плавным переходом. Вне квартиры, при скрытой вкладке, стартовом экране или вертикальной ориентации звук приостанавливается. Кнопка «Включить звук ТВ» доступна при блокировке автозапуска браузером.

## Обновление и проверка

```sh
npm run prepare:mom
npm run test:mom
```

`prepare:mom` обновляет только ограниченный маркерами `APARTMENT_MOM` блок основного HTML. Все медиа встроены в HTML; отдельные файлы нужны для дальнейшей разработки. Пересоздание той же гитарной мелодии: `npm run prepare:mom-media`, затем `npm run prepare:mom`.

Браузерная проверка проходит захват, включение, посадку, выключение и возвращение пульта с шагом 25 мс; проверяет расстояние от хвата до целевой позиции, посадку относительно дивана, реальное воспроизведение аудио, громкость по расстоянию и комнатам, выход/возвращение в квартиру, моргание, ожидание ванной и повторение всех 12 интервалов расписания на двух днях. Отчёт и снимки — `.preview/mom-qa/`.
