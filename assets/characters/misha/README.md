# Миша — студент кабинета 108

Добавлен 13 ноября 2026 года из пользовательского архива `5ea92504-7bae-4a48-8d7e-69c99798e210.zip`. Постоянный ID — `misha-108`, имя в игре и экспортированной модели — **Миша**. Голос пока не назначен.

## Модель и анимации

Оригинальные `base_basic_pbr.glb` и `base_basic_shaded.glb` сохранены локально в `source/`. Они содержат статическую модель в A-позе без скелета и анимаций. Папка исходников исключена из Git общим правилом проекта; для запуска игры она не нужна.

`scripts/prepare-misha.mjs` упрощает PBR-сетку с 1 000 000 до 36 000 треугольников, сохраняет 32 484 вершины, создаёт скелет из 15 суставов и нормализованные веса. Три исходные карты материала сохранены как WebP 1024×1024. Лицо, очки, одежда и пропорции взяты из присланной модели. Параметры и SHA-256 исходного GLB — в `preparation.json`.

Ходьба использует имеющийся в проекте перенос исходного `human_000089` из модели преподавателя НВП: `../students/natural-walk.json` и `student-locomotion.js`. Для Миши заданы цикл 1,38 м, скорость 1,30 м/с, отдельная фаза и размах рук. Захват ручки, открытие двери, отодвигание стула, посадка и спокойное сидение используют общий контроллер студентов и IK.

`misha-animated.glb` — самостоятельная модель с шестью клипами: `Student_Idle`, `Student_Walk`, `Door_Reach_Open`, `Chair_Pull`, `Sit_Down`, `Seated_Idle`. Дверь и стул в игре управляются отдельно от анимаций тела. Экспорт проверен обратной загрузкой и проигрыванием ходьбы.

## Расписание и место

**07:44 — начало движения из холла**, за турникетами, из точки `[0.85, 0, 8.975]` в координатах игры. До этого персонаж скрыт. Он проходит по коридорам к кабинету 108, берётся за ручку, открывает дверь, входит и закрывает её, подходит к парте, отодвигает стул, садится и придвигается. При свободном пути последовательность занимает около 37,45 реальной секунды: посадка завершается примерно в 07:56:29 игрового времени.

Место с красного круга на пользовательском снимке — левый стул у ближайшей парты, со стороны стены со стендами: `tableX=6.65`, `tableZ=13.32`, `side=-1`. Стул `misha-108-chair`: исходно `[6.38,0,13.035]`, после посадки `[6.146,0,13.035]`; корень сидящего персонажа `[6.165,0,13.035]`. Подход к сиденью проходит между парой стульев, чтобы не вести персонажа вдоль стены.

Персонаж участвует в общей очереди: ждёт игрока и других NPC, проходит дверь только после её открытия. Расписание повторяется каждый день и восстанавливается при возвращении в локацию или смене времени. Доступ: `locations.college1.misha108`, `.root`, `.model`, `.chair`, `.schedule`, `.sequence`, `.state`.

## Команды

- `npm run prepare:misha` — подготовить модель из сохранённого исходного PBR GLB и обновить только блок `MISHA_STUDENT` в основном HTML.
- `npm run export:misha` — экспортировать только Мишу в самостоятельный GLB с шестью анимациями.
- `npm run test:misha` — проверить время и точку старта, свободный маршрут, открытую дверь, очередь четырёх студентов, нужное место, ожидание игрока, повторение по дням, геометрию и веса.

Основной HTML содержит всю модель и текстуры. `misha-asset.json` — подготовленные данные для повторного использования. Снимки и отчёт проверки — `.preview/misha-qa/`.
