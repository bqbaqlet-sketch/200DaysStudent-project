# Общая ходьба студентов и движение по колледжу

Дима (`student-108`), Саня (`sanya-108`), Алексей (`alexey-108`) и Миша (`misha-108`) используют одну исходную скелетную ходьбу `human_000089` из пользовательской модели преподавателя НВП, перенесённую на их индивидуальные скелеты. Основные сетки, текстуры и пропорции Димы и Сани сохранены. Миша начинает маршрут из холла в 07:44; его модель и отмеченное пользователем место описаны в `../misha/README.md`.

## Перенос движения

`scripts/prepare-student-walk.mjs` считывает исходные скелет и клип из `../nvp-teacher/nvp-asset.json`, убирает поступательное движение корня и сохраняет 64 фазы цикла в `natural-walk.json`. Содержатся позиции таза и стоп, движения корпуса/головы, повороты стоп для переката и векторы рук. Во время игры исходный GLB не загружается — данные встроены в HTML.

`student-locomotion.js` переносит позиции через IK с учётом длины ног и рук конкретного студента. Фаза зависит от пройденного расстояния, поэтому постановка стоп согласована с движением персонажа. Сохранены перенос веса, повороты таза, противодвижение корпуса и головы. Кисти продолжают линию предплечья; для дверей используется отдельный захват ручки. Начало и остановка движения смешиваются с обычной стойкой через скорость маршрутной анимации.

## Проходы и очередь

`classroom-traffic.js` хранит участников по сцене. При движении NPC проверяет следующее положение относительно уже видимых участников: около 0,64 м между движущимися персонажами, 0,53 м возле сидящего. Если сближается слишком сильно — ждёт, сохраняя фазу маршрута. Вход занят — новый студент остаётся до входа, пока место не освободится. Обновление прибывающих персонажей идёт в порядке их времени прихода.

Двери дополнительно используют прежний `createClassroomDoorCrossing`: один владелец прохода, ожидание открытия, освобождение после выхода из проёма. Движение мебели привязано к личному стулу. Общее состояние маршрута — стабильный объект `.state`, поэтому данные остаются актуальными в обёртках персонажей.

Механизм ожидания применяется к прибывающим NPC в колледже; это локальное соблюдение дистанции на заданных маршрутах. Полноценного поиска обходных путей по навигационной сетке здесь нет.

## Самостоятельные модели и команды

`dima-animated.glb` и `sanya-animated.glb`, а также `../alexey/alexey-animated.glb` и `../misha/misha-animated.glb` содержат по шесть клипов: `Student_Idle`, `Student_Walk`, `Door_Reach_Open`, `Chair_Pull`, `Sit_Down`, `Seated_Idle`. Скелеты — по 15 суставов. Файлы проверяются повторной загрузкой через GLTFLoader и воспроизведением ходьбы.

- `npm run prepare:student-walk` — обновить общую ходьбу и встроенный блок `STUDENT_LOCOMOTION`.
- `npm run test:students` — пройти расписание и очередь, проверить место и геометрию.
- `npm run test:misha` — проверить путь Миши из холла, его место и взаимодействие четырёх студентов.
- `npm run export:students` — обновить шесть клипов в GLB каждого студента.
- `npm run preview:students` — записать превью четырёх студентов.

Проверки выполнялись непрерывными шагами 50 мс с 07:27 до 08:00 и с задержкой у турникетов до 08:10, отдельно — занятый вход и следующий день. Минимальная дистанция в испытании очереди — около 0,640 м; все студенты в итоге садятся. Дверь 108 в момент пересечения открыта, одновременно её пересекает один студент. Контроль движения стоп не выявил крупных скачков в опорной фазе. Проверки входов, квартиры и двора, а также маршрут НВП до 07:35 проходят. Отчёты и видео — `.preview/students108-qa/`.
