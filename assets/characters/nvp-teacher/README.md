# Преподаватель начальной военной подготовки

Добавлен 12 ноября 2026 года из присланной пользователем модели. Постоянный ID — `nvp-110`. Имя — Анатолий, сохранено только в неиспользуемом поле `NVP_TEACHER.characterName`. По просьбе пользователя имя пока не применяется в интерфейсе, репликах или поведении. Голос не назначен. Кабинет 110 — учительская.

## Файлы и присланные движения

- `source/base_basic_pbr.glb`, `source/base_basic_shaded.glb` — сохранённые оригиналы пользовательских файлов с суффиксом `(1)`; каждый содержит скелет и две анимации.
- `nvp-teacher-prepared.glb` — облегчённая PBR-модель с исходным скелетом и обоими оригинальными клипами, включая их движение корня.
- `nvp-asset.json` — данные для встроенной версии игры, включая обе анимации.
- `nvp-animation.js` — исходник контроллера персонажа и расписания.
- `color.webp`, `normal.webp`, `surface.webp` — карты 1024×1024; они также встроены в HTML.
- `preparation.json` — параметры оптимизации и имена клипов.

Сетка упрощена с миллиона до 36 000 треугольников, 29 092 вершины. Сохранены все 52 кости, включая пальцы. Для рендера Three.js r128 выбраны четыре наиболее сильных влияния на вершину из восьми исходных и нормализованы; средняя отброшенная доля веса около 0,0614%. Оригиналы сохранены полностью. meshoptimizer используется только при подготовке.

| Исходный клип | Имя в контроллере | Длительность | Использование |
| --- | --- | ---: | --- |
| `human_000089` | `NVP_Walk_Source` / `NVP_Walk_InPlace` | 1,0333 с | Присланная ходьба для текущего маршрута |
| `human_000000` | `NVP_Stance` | 8,8667 с | Сохранённая пользователем стойка для будущих сцен |

Стойка не подменена процедурной анимацией и не запускается во время ожидания у двери. В prepared GLB сохранены исходные имена и ключи обеих анимаций. Для текущей ходьбы контроллер устраняет только линейный перенос Hips по Z: положение в мире задаёт маршрут, а фаза шага следует пройденному расстоянию (исходный шаг около 1,8185 м). Это предотвращает удвоение перемещения и скачок при повторении цикла.

## Учительская и маршрут

В учительской 110 стоят общий стол, стулья по периметру, окна с жалюзи и другая мебель. У Айнуры, Людмилы Ивановны и Ларисы свои места, они сохранены. НВП занимает первый из двух существовавших боковых стульев у правого торца стола: локально `[4.88, 0, 2.695]`, поворот `-Math.PI/2`. Второй боковой стул остаётся свободным.

Маршрут: входная прихожая → турникеты → холл → коридор к 110 → открытие двери → проход вдоль свободного края комнаты → отодвигание бокового стула → подход спереди → посадка и придвигание. Дверь использует общий с другими сотрудниками механизм очереди. Посадка и нейтральные положения рук/ног рассчитываются IK поверх исходного скелета; стойка для этого не используется.

**К 07:35 персонаж уже сидит.** `NVP_TEACHER.seatedMinute` равен 455. `buildNvp110Routine` считает начало обратно от полного окончания последовательности: длительность около 21,2963 с, старт примерно 07:27:54 при 3 реальных секундах на игровую минуту. Поэтому в начальные игровые 07:30 преподаватель уже движется. Ожидание у занятого прохода может задержать персонажа, как и других NPC.

День берётся из общих часов: расписание повторяется на следующий день; вход в комнату позже 07:35 и возврат в локацию восстанавливают сидящего персонажа. Позы не накапливаются между кадрами. Ресурсы загружаются из основного HTML, дополнительных обращений к временным файлам нет.

## Продолжение разработки

Контроллер доступен через `activeWorld.nvp110` в первом корпусе. Он содержит `model`, `chair`, `schedule`, `sequence` и `update`. У модели есть `names`, `pose`, `clips.walk`, `clips.sourceWalk`, `clips.stance`, `sampleStance(seconds)`. Для будущей сцены со стойкой потребуется выбрать соответствующее состояние вместо обычного расписания; сейчас `sampleStance` является явным средством выборки позы.

```sh
npm ci
npm run prepare:nvp
npm run test:nvp
npm test
```

Подготовка меняет только блок `BEGIN NVP_TEACHER` / `END NVP_TEACHER` в основном HTML. Расстановка комнаты, подключение персонажа и её подписи находятся за пределами этого блока. Старый `sync-college1.py` не является способом сборки актуальной версии.

Браузерная проверка проходит весь маршрут без перемотки, проверяет открытый проход, посадку к 07:35, день 2, повторную синхронизацию, возврат в локацию, других сотрудников и геометрию сидящей модели. Отдельно сравнивает стойку с загруженным обратно GLB по всем костям. Результаты и снимок — `.preview/nvp110-qa/`.
