# Алексей — студент 108

Добавлен 13 ноября 2026 года из пользовательского архива `94d8db50-d48b-4c9b-aa83-7e068d4b5f75.zip`. Исходный OBJ без скелета и карты материала сохранены в `source/`. При подготовке основная сетка упрощена с 1 000 000 до 36 000 треугольников (27 643 вершины), добавлен скелет из 15 суставов и плавные веса. PBR-карты — WebP 1024×1024. Исходные UV переведены из ориентации OBJ в ориентацию игровых карт.

Постоянный ID — `alexey-108`, имя в коде — **Алексей**. Контроллер — `locations.college1.alexey108`, модель — `.model`, маршрут и этапы — `.sequence` / `.schedule`, текущее состояние — `.state`.

## Приход и место

**07:34 — начало входа в колледж**, а не срок окончания посадки. Алексей появляется у внутренней входной зоны, проходит турникеты, холл и коридоры, захватывает ручку двери 108, открывает её, проходит внутрь, закрывает дверь, подходит к своему месту, отодвигает стул, садится и придвигается к парте. Без задержек весь путь занимает около 45,12 реальной секунды; при текущих часах он сидит примерно к 07:49. Если проход занят, прибытие к парте откладывается.

Место выбрано по красной отметке пользователя: у окна, на один ряд ближе к доске, чем Дима. В плановых координатах кабинета: `tableX=4.95`, `tableZ=16.69`, `side=1`. Стул `alexey-108-chair`: начальная позиция `[4.68,0,16.975]`, после посадки `[4.446,0,16.975]`; корень персонажа после посадки `[4.465,0,16.975]`. Чужие места не занимает. Стулья Димы и Сани сохранены.

Распорядок повторяется по дням, восстанавливается при загрузке локации и `gameTime.set()`. До начала прихода персонаж скрыт. В занятом входе ждёт свободного места, у турникетов и двери соблюдает дистанцию; дверь 108 обслуживает одного NPC за раз.

## Анимации

Для Алексея, Димы и Сани ходьба заменена переносом исходного скелетного клипа `human_000089` с модели НВП на их скелеты через IK. У Алексея длина цикла шага 1,42 м, скорость маршрута 1,34 м/с, отдельная фаза и более спокойный размах рук. Движение стоп согласовано с пройденным расстоянием; переносятся движение таза, работа корпуса и головы, перекат стопы и движения рук. Кисти при ходьбе расслаблены; захват дверной ручки управляется отдельно.

`alexey-animated.glb` содержит:

- `Student_Idle` — ожидание;
- `Student_Walk` — циклическая ходьба;
- `Door_Reach_Open` — захват и работа с ручкой;
- `Chair_Pull` — движение для отодвигания стула;
- `Sit_Down` — посадка;
- `Seated_Idle` — ожидание сидя.

В игре дверь и стул — отдельные объекты, которыми управляет маршрут. В самостоятельном GLB сохранены анимации тела без геометрии помещения и мебели. Голос и реплики Алексею пока не назначены.

## Подготовка и проверка

`npm run prepare:alexey` обновляет модель и блок `ALEXEY_STUDENT` основного HTML. Общая ходьба и очередь находятся в `assets/characters/students/`; команда `npm run prepare:student-walk`. `npm run export:students` сохраняет самостоятельные GLB всех трёх студентов; `npm run preview:students` записывает демонстрацию ходьбы.

`npm run test:students` проверяет вход в 07:34, маршрут через турникеты, последовательный проход открытой двери, отмеченное место, ожидание в очереди и занятом входе, повторение на следующий день, геометрию поз и постановку стоп. Превью и отчёты — `.preview/students108-qa/`. Локальная игра обновлена; публикация на GitHub Pages отдельно не выполнялась.
