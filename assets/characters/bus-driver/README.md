# Водитель автобуса

Персонаж сюжетной мобильной игры 200DaysStudent из пользовательских моделей, добавлен 12 ноября 2026 года. Постоянный ID — `bus-driver`. Имя, голос и реплики пока не назначены.

## Ресурсы

- `source/base_basic_pbr.glb` — исходная модель, выбранная для игры; миллион треугольников, без скелета и анимаций.
- `source/base_basic_shaded.glb` — сохранённая альтернативная версия с запечённым освещением.
- `driver-asset.json` — упакованные сетка, веса, скелет и PBR-карты; этот же объект встроен в основной HTML.
- `driver-animation.js` — редактируемый контроллер; команда подготовки обновляет соответствующий блок HTML.
- `bus-driver-animated.glb` — отдельная модель со скелетом и четырьмя анимациями.
- `color.webp`, `normal.webp`, `surface.webp` — текстуры 1024×1024.
- `preparation.json` — параметры подготовки.

Подготовленная модель: 36 000 треугольников, 26 401 вершина, 17 костей, включая сгиб пальцев. Новая лицензия на пользовательские материалы не назначена.

## Анимация

`buildBusDriver()` возвращает `root`, `names` и `sample(time, {speed, doors, phase})`. Время и скорость берутся из общего маршрута. Поза рассчитывается напрямую, не накапливает повороты и не перезапускается при переходе сцен. Две копии автобуса разделяют геометрию и материалы, но имеют независимые скелеты. В неактивной локации поза каждый кадр не рассчитывается.

На остановке водитель дышит и поглядывает к двери при посадке/высадке. На ходу — держит руль двумя руками через IK, немного подруливает, двигает корпусом, поглядывает в зеркало и работает правой ногой у педали. Пальцы согнуты вокруг обода. Руль выделен из исходной модели и вращается согласованно с руками; колонка и панель неподвижны.

В GLB записаны клипы с частотой 24 ключа/с и сведёнными для повторения окончаниями:

| Клип | Длительность |
| --- | ---: |
| `Driver_Idle` | 8 с |
| `Driver_Driving` | 10 с |
| `Driver_DoorCheck` | 8,8 с |
| `Driver_MirrorCheck` | 7,3 с |

В самой игре работает процедурный контроллер, а GLB — самостоятельный переносимый ресурс.

## Подготовка и проверка

После `npm ci`, из корня проекта:

```sh
npm run prepare:driver
npm run test:driver
npm run test:bus
npm run export:driver
```

`scripts/prepare-bus-driver.mjs` читает сохранённый PBR-исходник, упрощает сетку с сохранением UV/нормалей через meshoptimizer 1.3.0, уменьшает текстуры и назначает веса. Перезаписывает только блок `BEGIN BUS_DRIVER` / `END BUS_DRIVER` в HTML. Подключение в `buildTransportBus` / `createBusTransit` находится за пределами блока.

Проверка использует локальный Three.js: проверяет веса, деформацию внутри кабины, положение кистей у исходного обода, независимость скелетов и разделение ресурсов. Экспорт дополнительно загружает полученный GLB обратно и запускает анимацию. Отчёт и снимок — в `.preview/driver-qa/`.

Для будущих реплик сохранены `characterId`, `role: 'driver'`, `dialoguePending: true`. Контроллер доступен как `busTransit.fleet.get(location).driver`. Лицевой риг и липсинк пока не добавлены.
