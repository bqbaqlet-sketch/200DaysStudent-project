# Общие подогнанные глаза

`fitted-eyes.js` используется только Ильёй (`student-front-108`) и продавцом магазина одежды (`clothing-shop-seller`). Другие персонажи сохраняют свои реализации.

Геометрия следует профилю лица и кости головы, имеет небольшую выпуклость в области глазного яблока. Радужка и зрачок рисуются на отдельной текстуре с прозрачной круглой границей; текстура кожи вокруг век подбирается по исходному лицу. Текстуры глаз 768×384 дают плавный контур на крупном плане. Моргание закрывает глаз сверху, сохраняя кожный слой поверх дефектов первоначальной модели.

Материал берёт настройки исходного лица, включая карту излучения, умноженную на новую текстуру. Постоянное излучение белков не добавляется. Canvas перерисовывается только при изменении взгляда или век. Индивидуальные размеры, высота, радужки и ритм моргания задаются обёртками в папках персонажей.

Синхронизация любого из двух персонажей обновляет единственный блок `FITTED_CHARACTER_EYES` в игровом HTML через `scripts/lib/embed-fitted-eyes.mjs`. Проверка: `npm run test:eyes`, снимки — `.preview/eyes-revision-qa/`.
