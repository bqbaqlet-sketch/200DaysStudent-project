# Охранник Медведев

Персонаж будущей сюжетной мобильной игры, постоянный ID `guard-medvedev`. Добавлен из файлов пользователя `base_basic_pbr (2).glb` и `base_basic_shaded (2).glb` 12 ноября 2026 года. Исходники сохранены в `source/`; в игре используется PBR-вариант.

Основная сетка облегчена с 1 000 000 до 36 000 треугольников, 39 143 вершины, 52 исходные кости. Исправленные глаза добавляют 3 456 треугольников и два вызова отрисовки; всего 39 456 треугольников. Три текстуры WebP 1024×1024. `medvedev-prepared.glb` сохраняет три исходных клипа: `human_000000` (стойка), `human_000089` (ходьба), `human_000093` (спокойное ожидание). В расписании используется ожидание и ходьба с компенсацией перемещения корня. Стойка сохранена отдельно для будущих сцен.

## Исправление глаз

По замечанию пользователя исходная область глаз почти не отличалась от кожи. Добавлены две небольшие изогнутые поверхности глаз, подогнанные по глубине существующей сетки и форме возрастных век: приглушённые белки, серо-голубые радужки с рисунком волокон, тёмные зрачки и мягкие края. Поверхности привязаны к исходной кости `Head`, поэтому следуют за головой во всех присланных анимациях. В игре добавлено короткое моргание длительностью 0,17 с примерно раз в 5,9 с.

`medvedev-eyes.mjs` — общая геометрия и материал для игры и экспорта. `eye-profile.json` — форма, положение и глубина посадки обеих глазных поверхностей. `scripts/fit-medvedev-eyes.cjs` пересчитывает глубину по основной сетке после изменения параметров профиля. Затем `node scripts/prepare-medvedev.mjs` обновляет встроенную модель и GLB. Глаза в GLB находятся дочерними узлами `Head`; исходные три клипа сохранены. Моргание задаётся контроллером игры.

Основная сетка, три текстуры, исходный скелет и исходные анимационные данные сохранены побайтно. Другие персонажи и распорядок Медведева не затронуты. Проверены крупный вид спереди и сбоку, совпадение движения глаз в игре и экспортированном GLB; существующая проверка расписания и озвучки проходит.

## Распорядок

Все времена игровые, повторяются ежедневно. При текущем масштабе одна игровая минута равна трём реальным секундам.

| Время | Поведение |
|---|---|
| 00:00–07:00 | Остаётся внутри будки |
| 07:00 | Встаёт, открывает дверь, выходит к посту (около 9,52 с) |
| После выхода–09:00 | Спокойно стоит у КПП |
| 09:00–10:00 | Стоит; при приближении игрока говорит «Быстрее, когда уже пары начались?» |
| 10:00–11:00 | Спокойно стоит |
| 11:00 | Открывает дверь, поднимается по ступеням, проходит внутрь, закрывает дверь и садится (около 10,24 с) |
| После входа–13:00 и далее | Остаётся сидеть внутри до 07:00 следующего дня |

Незаполненные пользователем промежутки 08:00–09:00 и 10:00–11:00 трактуются как спокойное ожидание. Вход и выход — непрерывные анимации. Если игрок преграждает путь, охранник ждёт и продолжает после освобождения прохода. Пропущенное время восстанавливается при смене локации или `gameTime.set()`.

Реплика срабатывает при подходе ближе 3,1 м, один раз за посещение; для повторения нужно отойти дальше 4,5 м и вернуться, минимальная пауза 6 с. До 09:00 и с 10:00 реплика отключена. При скрытии вкладки, выходе из локации, вертикальном экране или удалении дальше 9 м звук останавливается. Если браузер блокирует автозапуск, появляется кнопка включения звука. Точная формулировка реплики сохранена.

## Голос

Постоянный профиль `medvedev-ru`, генератор [Qwen3-TTS VoiceDesign](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign), официальный публичный [демосервис Qwen](https://huggingface.co/spaces/Qwen/Qwen3-TTS). Задан пожилой русскоязычный мужчина около 70 лет, низкий баритон с лёгкой хрипотцой, ворчливая строгая подача. Синтетический голос не основан на записи конкретного человека.

Готовая фраза: `assets/voices/medvedev-hurry.wav`, 24 kHz mono PCM16, 2,537 с. Референс для следующих реплик: `assets/voices/medvedev-reference.wav`; точная расшифровка, описание, исходный запрос, источник и обработка сохранены в `assets/voices/medvedev-voice.json`. Для новых фраз сохранять этот голос: использовать референс и расшифровку с Qwen3-TTS Base (Voice Clone), а не создавать новый случайный голос через VoiceDesign. Лицензия модели — Apache-2.0; см. карточку модели.

## Код и проверка

- `medvedev-animation.js`: модель, исходные клипы и `createMedvedevRoutine`.
- `scripts/prepare-medvedev.mjs`: подготовка GLB и обновление встроенного блока `MEDVEDEV_CHARACTER` основного HTML. Использует сохранённую запись, повторно голос не генерирует.
- `.preview/guard-post-exterior.js`: полая будка с окнами, рабочим местом и открывающейся служебной дверью. Для игрока прежний закрытый контур поста сохранён.
- `locations.college.medvedev`, `locations.college.guardPost`: доступ из игры; `characterVoices.medvedev`, `medvedevDialogue.hurry`: голос и реплика.
- `npm run prepare:medvedev`, `npm run test:medvedev`. Проверяются часы на границах, два игровых дня, проход через открытую дверь, ожидание игрока, повторные подходы, уход из локации и воспроизведение настоящего встроенного WAV. Превью и отчёт: `.preview/medvedev-qa/`.

И модель, и звук встроены в основной HTML. Временные исходные пути на компьютере пользователя во время игры не нужны. Текущая реализация находится в локальном проекте; публикация GitHub Pages — отдельное действие.
