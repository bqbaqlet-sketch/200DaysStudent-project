# Илья — студент за первой партой в 108

Модель пользователя `d40127a3c28c9dcf48ed6df7d8dda67c.glb`, референс — `reference.jpg`. Имя **Илья** задано пользователем и сохранено в `FRONT_STUDENT.characterName`, метаданных модели, имени контроллера и `root.userData.characterName`. Голос не назначен. Постоянный ID — `student-front-108`, доступ — `locations.college1.frontStudent108`.

Исходный GLB сохранён локально в `source/original.glb` и не нужен для запуска игры. В нём 1 498 512 треугольников, нет скелета и анимаций; исходный поворот узла применён перед нормализацией роста до 1,82 м. Подготовленная модель: 48 000 треугольников, 34 322 вершины, скелет из 15 суставов; цветовая карта WebP 1536×1536, остальные карты — 1024×1024. Суставы и веса подогнаны к его плечам, локтям и кистям. Метаданные и SHA-256 — `preparation.json`.

Глаза исправлены по референсу: сглажены дефекты вокруг век, добавлены тёмно-карие радужки, узкий разрез глаз, небольшие блики и моргание. Кожа вокруг век берётся из исходной текстуры. `eye-profile.json` привязывает поверхность к голове; `student-eyes.js` управляет веками и направлением взгляда.

В 07:43 он начинает идти из холла `[0.85, 0, 8.975]`, проходит коридоры, открывает дверь 108, отодвигает стул и садится. При свободном проходе маршрут занимает около 37 с, посадка заканчивается около 07:55:20; с обычной очередью пяти студентов — примерно 07:55:47. Занятый проход задерживает движение, через игрока он не проходит. Расписание повторяется по дням и восстанавливается при возвращении в сцену.

Место с красного круга: левый стул у первой парты правого ряда, `tableX=6.65, tableZ=15.51, side=-1`. После посадки персонаж находится в локальной точке `[6.165, 0, 15.225]`, стул — `[6.146, 0, 15.225]`. Остальные четыре студента сохраняют свои места.

Ходьба использует сохранённую исходную анимацию НВП через общий контроллер студентов. За партой доступны дыхание, кивок, взгляд в сторону, поправление манжеты, перемена позы и движение кисти у столешницы. При приближении игрока персонаж ненадолго переводит к нему взгляд. Движения рук используют IK, небольшие действия плавно начинаются и заканчиваются.

Команды: `npm run prepare:front-student`, `npm run test:front-student`. Подготовка требует локального исходного GLB. Игра содержит все готовые данные в блоке `FRONT_STUDENT` основного HTML. Проверка проходит маршрут всех пяти студентов, очередь при перекрытии холла, дверь, посадку до 08:00, повторение по дням, анимации, моргание и взгляд на игрока. Отчёт и изображения — `.preview/front-student-qa/`.

Обновление 14 ноября: глаза используют общую реализацию `assets/characters/shared/fitted-eyes.js` с текстурами высокого разрешения и освещением исходного лица. Индивидуальные параметры и профиль поверхности остаются в папке персонажа. Проверка: `npm run test:eyes`.
