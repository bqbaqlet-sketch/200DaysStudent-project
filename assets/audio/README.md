# Звуки игры

`game-audio.js` — общий контроллер Web Audio. `npm run prepare:world-audio` встраивает код и сжатые записи в основной HTML: эффекты работают через `file://` и без обращений к сторонним серверам. Оригинальная музыка Treblo по-прежнему хранится отдельно в `assets/menu/`.

Звуки привязаны к состоянию игры:

- На улице — новые записи настоящей обуви по бетону и траве Joseph SARDIN / BigSoundBank. Для каждого покрытия четыре варианта с мягкой атакой и выровненной громкостью; один вариант не повторяется подряд. Ритм уличной ходьбы снижен примерно до 2,5 шага/с, бега — до 3,5 шага/с при стандартных скоростях контроллера. Внутри сохранены отдельные шаги по твёрдому покрытию и дереву. Нет шагов при остановке, столкновении, полёте, сидении и поездке пассажиром. Ближайшие идущие NPC также слышны.
- Двигатель автобуса меняет тон со скоростью. Расстояние и сторона относительно игрока влияют на слышимость. Пневматика звучит при движении дверей и торможении; внутри автобуса сохраняется двигатель.
- Скрип качелей возникает при смене направления; карусель слышна при вращении. Двери кабинетов и квартиры, шифонер, переодевание, сиденья и кнопки имеют свои эффекты.
- На улице — птицы, ветер, ночные насекомые и расположенный у фонтана звук воды. Внутри — тихий фон помещения, короткие отражения, шаги и движение мебели. В колледже есть звонок по расписанию без серии повторов после перемотки.
- Мотор и остановка шлагбаума звучат при его реальном движении.

В настройках отдельные ползунки музыки меню, эффектов и окружения. Значения 0–100% сохраняются в `200daysstudent.settings`, независимо от будущих сохранений прохождения. Существующие реплики персонажей и телевизор сохраняют собственные контроллеры. Во время паузы, главного меню, скрытой вкладки, потери фокуса и вертикального положения телефона игровые эффекты и петли останавливаются.

33 файла занимают 547 766 байт до кодирования base64. Короткие записи декодируются однократно после первого пользовательского ввода; общий объём декодированных данных около 12 МБ. Одновременно допускается не более 24 коротких эффектов; неслышимые пространственные петли не запускаются. Для отражений применён короткий delay вместо тяжёлой свёртки.

## Источники

Все добавленные сторонние записи имеют CC0 1.0. Ссылки на страницы авторов, исходные загрузки, используемые файлы, преобразования и SHA-256 — в `sources.json`.

| Источник | Использование |
| --- | --- |
| [Kenney — Impact Sounds](https://kenney.nl/assets/impact-sounds) | Шаги в помещениях по твёрдому покрытию и дереву; исходные OGG сохранены |
| [Joseph SARDIN — Shoe on Concrete](https://bigsoundbank.com/footsteps-shoe-on-concrete-s0514.html), [Tall Grass](https://bigsoundbank.com/courir-dans-l-herbe-haute-s1843.html) | Новые уличные шаги: отдельные удары обуви, фильтрация, нормализация и короткие плавные края |
| [Kenney — RPG Audio](https://kenney.nl/assets/rpg-audio) | Скрип механизмов |
| [Kenney — UI Audio](https://kenney.nl/assets/ui-audio) | Кнопки интерфейса |
| [laleksic — Various Sound Effects](https://opengameart.org/content/various-sound-effects) | Двери, ящики, мебель, металл, вода, звонок; нарезка и сжатие в mono MP3 |
| [Spring — Birds and Wind](https://opengameart.org/node/93987) | Уличное окружение; птицы также за авторством isaiah658, syncopika и pauliuw |
| [LEGIT Audio — The Shop](https://opengameart.org/content/the-shop) | Фон помещений из бесплатного набора OpenGameArt |
| [SFXMint — Passing Bus Engine 02](https://sfxmint.com/sounds/bus-engine-02) | Петля двигателя; автор помечает оригинал как AI-generated |

Kenney предоставлен через публичное зеркало [open-game-sfx-index](https://github.com/Mcamento8/open-game-sfx-index), лицензия проверена на страницах Kenney. Ветер, пневматика и ночные насекомые синтезируются собственным кодом без сторонних записей. Условия CC0: https://creativecommons.org/publicdomain/zero/1.0/.

## Проверка

`npm run test:world-audio` запускает настоящий Edge/WebGL/Web Audio, проверяет ненулевой аудиосигнал, шаги/остановку/полёт, дистанцию и скорость автобуса, пневматику, двери, площадку, паузу, сохранение трёх настроек и автоматический запуск музыки меню. Также проходит реальные лестницы и пандусы и проверяет сенсорный джойстик, удержание входа и выход на площадку в размерах 844×390 и 568×320. Это эмуляция мобильного браузера, не физический Android. Отчёт и снимки — `.preview/world-audio-qa/`.
