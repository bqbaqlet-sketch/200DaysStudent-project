# Русский текст локаций

`map-ru.json` содержит переводы исходных казахских надписей. `npm run prepare:map-ru` обновляет основной HTML и редактируемые фрагменты геометрии в `.preview/`, сохраняя расположение объектов. Архивные варианты `before`, `v1`, `v2` не используются игрой и не переписываются.

В `textures/` лежат русские версии встроенных картинок: плакат робототехники, карта Казахстана с прозрачным фоном и атлас семи стендов НВП. Подготовка встраивает их как data URL, поэтому они работают и при запуске через `file://`. Сетки атласа и координаты вырезания сохранены. Изображения локализованы по оригинальным текстурам с помощью imagegen; мелкий неразборчивый текст заменён краткими русскими тематическими подписями. Имена собственные и бренды сохранены.

В кабинете 108 старая фотография казахского изречения заменена рисуемой табличкой с русским девизом об истории, без приписывания его историческому автору. Из портретов вырезаны старые мелкие подписи.

`npm run test:map-ru` перехватывает фактически нарисованные надписи всех шести локаций, проверяет отсутствие казахских букв и делает снимки локаций в размерах 1600×900, 844×390 и 568×320 с эмуляцией касаний Android. Это эмуляция браузера, не проверка на физическом телефоне. Отчёт и снимки: `.preview/russian-mapping-qa/`.

После изменения видимых стендов в кабинете 108 обновлять фон главного меню: `node .preview/check-map-russian.cjs --export-menu-background`, затем `npm run prepare:menu`.
