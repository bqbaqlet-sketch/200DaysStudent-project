# Голоса персонажей

13 ноября 2026 года озвучка Медведева и Ларисы заменена четырьмя MP3, переданными пользователем. Файлы скопированы без перекодирования, обрезки и изменения громкости. Субтитры содержат только произносимую реплику, без имени персонажа.

| Персонаж / событие | Файл | Реплика | Длительность |
| --- | --- | --- | --- |
| Медведев, замечание опоздавшему | `medvedev-hurry.mp3` | Где тебя носит? Пары начались в восемь. | 3,161 с |
| Лариса, первый стук | `larisa-first.mp3` | Кто там стучит? | 1,567 с |
| Лариса, повторный стук | `larisa-second.mp3` | Ну же, заходи давай! | 1,802 с |
| Лариса, вход без разрешения | `larisa-eject.mp3` | Ты что, совсем избалованный? | 2,508 с |

Голоса в названиях пользовательских файлов: **Alexrady** для Медведева и **Natalia - Gentle and Soothing** для Ларисы. Постоянные игровые ID сохранены: `medvedev-ru`, `larisa-ru`. Полные исходные имена файлов, точные длительности воспроизведения, тексты, SHA-256 и текущие голосовые профили — в `dialogue.json`. Расшифровка выполнена локальным Faster Whisper base на русском; пунктуация и орфография приведены к обычному письменному виду.

Активный референс Медведева — `medvedev-hurry.mp3`, Ларисы — `larisa-first.mp3`. `medvedev-voice.json` и `larisa-voice.json` описывают текущие пользовательские записи. Старые WAV и `medvedev-qwen-voice.json` сохранены как история и в текущую игру не подключаются. Новые голоса следует согласовывать с текущими MP3.

```sh
npm run prepare:voices
npm run test:voices
```

Подготовка проверяет контрольные суммы и обновляет только `characterVoices`, `medvedevDialogue` и `director110Dialogue` в игровом HTML. MP3 встраиваются как `data:audio/mpeg`; во время игры не нужны отдельные файлы или голосовые сервисы. `prepare:medvedev` также читает текущую реплику из `dialogue.json`, поэтому повторная подготовка персонажа сохраняет новую озвучку.

Срок показа субтитров и задержки ответа/выхода учитывают длительность новых записей. Браузерная проверка сверяет байты и тексты, декодирует все MP3, воспроизводит каждую реплику до конца через игровые обработчики, проверяет отображение субтитров до завершения звука и отсутствие ошибок. Отчёт — `.preview/voices-qa/report.json`. Проверка расписания, повторного подхода и отключения голоса Медведева — `npm run test:medvedev`.
