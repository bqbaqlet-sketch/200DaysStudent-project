# Медиа телевизора

- `mom-screen.jpg` — пользовательское вложение `codex-clipboard-7fa644b9-8f6f-45fe-8fbb-b850fb6fc35e.jpg`, скопированное без изменения. На ТВ показывается вся картинка с сохранением пропорций.
- `mom-guitar.wav` — оригинальная инструментальная мелодия, созданная кодом для игры: гитарный перебор, 78 BPM, Am–F–C–G / Am–F–G–Am, 24,615 с, бесшовный цикл. Это отдельная мелодия; аудио из изображённых на картинке роликов не использовано.
- `mom-media.json` — характеристики мелодии и происхождение картинки.
- `credits.txt` — сведения о текущих медиа и атрибуция фильма из предыдущей версии игры.

Синтез гитарных струн использует алгоритм Карплуса — Стронга, с детерминированным шумом щипка, затуханием и небольшим реверберационным хвостом. Скрипт `scripts/prepare-mom-media.cjs` воспроизводит тот же WAV без сетевых сервисов и библиотек синтеза. Звук не содержит речи.

Картинка и WAV встроены в основной HTML через `scripts/prepare-mom.mjs`. Файлы из этой папки при запуске отдельно не загружаются.
