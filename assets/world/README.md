# Коллизии двора колледжа

`college-collision.js` один раз читает фактические трансформации статической геометрии обоих фасадов, спортплощадки и помеченных твёрдых деталей двора. Работает с обычными Mesh и InstancedMesh. У площадок, ступеней, тротуаров и пандусов есть опорные поверхности; у перил, скамеек, стоек и остальных твёрдых деталей — коллизии с учётом высоты. Высокие навесы не закрывают проход под ними.

`locations.college.walkGroundAt(x,z,feet)` возвращает высоту покрытия. Обычный подъём ограничен 23,5 см за шаг; высокий бок площадки пройти нельзя. Пандусы имеют непрерывную высоту. `collisionMapping` содержит поверхности, препятствия и точную проверку движущейся стрелы шлагбаума. Входы в корпуса считают доступность от высоты ног на площадке; при выходе игрок ставится на реальную высоту крыльца.

Геометрия и отрисовка сохраняются; коллизии не создают дополнительных видимых Mesh и не используют покадровые raycast по всей карте. Синхронизация — `npm run prepare:world-audio`; проверка — `npm run test:world-audio`. После изменения геометрии снова выполнить синхронизацию.
