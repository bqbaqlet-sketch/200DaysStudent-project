# Пасхалка на пятом этаже

`spongebob-totya.webp` — точное изображение из пользовательского вложения `codex-clipboard-51c4ba39-285d-40b4-aaf1-f05af8ff18f9.webp`. Размер 398×320; содержимое не редактировалось.

В подъезде 4 мем висит на дальней стене площадки пятого этажа, на высоте 13,45 м от пола первого. Ширина 0,78 м, высота сохраняет пропорции исходника. Плакат — часть сцены, без всплывающего окна. Доступ: `locations.entrance4.easterEgg`.

`npm run prepare:entrance` встраивает изображение вместе с исходником подъезда в ограниченный блок `ENTRANCE_INTERIOR` основного HTML. Игровой файл работает без отдельного запроса этой картинки. `npm run test:entrance` проверяет этаж, размеры и полное совпадение встроенных байтов с исходником.
