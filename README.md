# 200DaysStudent

[▶ Играть в 200DaysStudent](https://bqbaqlet-sketch.github.io/200DaysStudent-project/)

На телефоне откройте игру в горизонтальном положении.

Будущая сюжетная мобильная 3D-игра про жизнь студента. Текущий браузерный прототип: колледж, жилой двор, квартира, персонажи с расписанием и автобус между домом и колледжем.

Основная рабочая папка по указанию пользователя: `C:\Users\baqle\OneDrive\Desktop\200DaysStudent-project`. В неё перенесены все актуальные изменения, включая шифонер, форму и переодевание.

## Запуск

Откройте основной HTML-файл в корне проекта в современном браузере. В нём находятся игровой код, модели персонажей, текстуры, звук и реплики. Для загрузки Three.js 0.128.0 с CDN нужен интернет.

Можно запустить локальный сервер через Node.js 20 или новее:

```sh
npm start
```

Откройте http://127.0.0.1:8000. Сборка не требуется.

## Управление

- WASD — движение; мышь с зажатой кнопкой — обзор.
- E или экранная кнопка — взаимодействие, вход в автобус, выбор сиденья и выход.
- Shift — ускорение; F — полёт на улице; пробел / C — вверх / вниз в полёте.
- L — смена локации вне автобуса.
- T или нажатие на часы — перемотка назад/вперёд на 10 минут, час или день и переход к точному дню и времени. Меню ставит игру на паузу; Esc или «Продолжить игру» возвращает в игру. Перемотка доступна после выхода из автобуса.
- На телефоне: движение слева, обзор справа; нужен горизонтальный экран.
- Шифонер в комнате квартиры: подойдите и нажмите E, экранную кнопку или саму створку. Повторное нажатие закрывает шкаф; двери плавно сдвигаются одна за другую.
- Переодевание: откройте секцию с четырьмя вешалками, наведитесь на одежду и удерживайте E, экранную кнопку или саму одежду 1,1 с. Предыдущий комплект займёт ту же вешалку; его можно надеть обратно.

- Площадка во дворе: работают только качели и карусель, остальное оборудование остаётся декорацией. Подойдите и нажмите E либо экранную кнопку; на телефоне можно коснуться самого оборудования. Удерживайте W или кнопку действия для разгона, S или «Тормоз» — для торможения. E, Esc или «Сойти» завершает катание и выводит на свободное место после остановки.

## Содержимое

- Основной `*.html` в корне — актуальная игра.
- `assets/` — подготовленная модель автобуса, голоса персонажей и медиа телевизора.
- `assets/characters/bus-driver/` — водитель, сохранённые исходники, облегчённая модель со скелетом и анимациями.
- `assets/characters/nvp-teacher/` — преподаватель НВП, исходная ходьба и сохранённая для будущих сцен стойка. Он приходит в учительскую 110 и к 07:35 занимает боковой стул.
- `.preview/` — проверки, снимки игры, вспомогательные и исторические фрагменты сцен.
- `.backups/` — предыдущие сохранённые версии.
- `PROJECT_CONTEXT.md` — сюжет, техническое состояние и договорённости для продолжения разработки в новом чате.
- `PROJECT_OVERVIEW.md` — карта реализации, состояние сюжетных и мобильных систем и результаты технического изучения.

Все исходные файлы проекта, включая резервные версии и снимки, сохранены. Актуальной версией игры служит основной HTML; старые фрагменты в `.preview/` — история разработки.

## Проверки

```sh
npm ci
npm test
npm run test:bus
npm run test:driver
npm run test:nvp
```

Браузерная проверка использует Microsoft Edge на Windows. Если Edge нет, установите Chromium командой `npx playwright install chromium`. Путь к своему браузеру можно передать через `PLAYWRIGHT_EXECUTABLE_PATH`.

Дополнительно: `npm run test:college2` проверяет второй корпус в браузере. Отчёты и снимки сохраняются в `.preview/`.

`npm run test:wardrobe` проверяет открытие и закрытие шифонера с клавиатуры, касанием створки и экранной кнопки, плавный разворот анимации, защиту от случайного открытия при свайпе и сохранение положения створок при смене локации.

`npm run test:outfits` проверяет форму, обмен одеждой и сенсорное удержание. Подготовка модели — `npm run prepare:uniform`; экспорт исправленного героя с анимациями — `npm run export:uniform`. Ресурсы и описание — `assets/characters/player-uniform/`.

`npm run test:entrance` проверяет подъём и спуск через пять этажей, десять разных дверей с номерами 31–40, вход в квартиру 33 на втором этаже, верхние перила, нижнюю нишу, окна и пасхалку на пятом этаже. Исходник подъезда — `.preview/entrance-interior.js`, обновление ограниченного блока игры — `npm run prepare:entrance`. Результаты — `.preview/entrance-qa/`.

`npm run test:playground` проверяет все качели и карусель в обычной одежде и форме: посадку, движение, хват пальцами, положение и направление кистей, возврат обычной позы, остановку, свободный выход, клавиатуру и касания. Другие объекты площадки проверяются как декорации. Исходники — `.preview/home-location.js` и `.preview/playground-runtime.js`; `npm run prepare:playground` встраивает их в блок `HOME_LOCATION`. Отчёт и снимки — `.preview/playground-qa/`.

В 108 добавлен Илья из нового пользовательского GLB, с исправленными по референсу глазами. В 07:43 он выходит из холла и до 08:00 садится на отмеченный левый стул первой парты правого ряда. Есть моргание, взгляды, кивок, поправление манжеты и другие спокойные движения. Ресурсы — `assets/characters/student-front108/`, команды — `npm run prepare:front-student` и `npm run test:front-student`.

В магазине одежды работает продавец из пользовательской модели: с 06:00 до 22:00 стоит за кассой, затем выходит из магазина и уходит во двор. Дорисованы глаза и добавлено моргание. Ресурсы — `assets/characters/clothing-seller/`, подготовка — `npm run prepare:clothing-seller`, проверка расписания, маршрута и мобильного вида — `npm run test:clothing-seller`.

`npm run prepare:driver` обновляет встроенную модель и анимации водителя из сохранённых исходников. `npm run export:driver` проверяет и экспортирует отдельный GLB с четырьмя анимациями.

`npm run prepare:nvp` обновляет модель преподавателя НВП и встроенный контроллер. Проверка `test:nvp` проходит маршрут с обычным течением часов, проверяет дверь и посадку к 07:35, повторение по дням и сохранность присланной стойки.
